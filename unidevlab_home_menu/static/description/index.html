A clean app launcher home screen for Odoo

Full-page launcher that lists every app and lets you search apps and menus in one keystroke.
全頁應用程式啟動首頁，把每個應用程式排成格子，一鍵搜尋應用程式與選單。

01Full-page app launcher

A clean home screen that lists every installed application as a tile, one click away.
全頁啟動首頁：每個已安裝應用程式排成格子，一眼點選。

02Search apps and menus

Type to instantly filter applications and their sub-menus, then jump straight to any screen.
搜尋應用與選單：輸入即時過濾，直接跳到任何畫面。

03Community only, no Enterprise

Uses Community webclient APIs only. No web_enterprise, no subscription files, no publisher-warranty calls.
純社群版：零 Enterprise 依賴、不含訂閱檔與授權回呼。

04Odoo 18 & 19

One clean-room module that works on both 18.0 and 19.0.
支援 18 與 19：同一套模組通用兩個版本。

05Set as your home

Opens at /odoo/home, so you can point users here as the default landing screen.
設成首頁：路徑 /odoo/home，可當預設登入畫面。

06Lightweight & LGPL-3

Tiny footprint, depends only on web. Free and open source.
輕量開源：只相依 web，免費、LGPL-3 授權。

Installation · 安裝步驟

01Add the module to your addons path · 放入 addons 路徑

Copy the unidevlab_home_menu folder into your Odoo addons directory.
將 unidevlab_home_menu 資料夾放進你的 Odoo addons 目錄。

02Update app list and install · 更新清單並安裝

Apps → Update Apps List → search Community Home Menu → Install.
應用程式 → 更新應用程式清單 → 搜尋「Community Home Menu」→ 安裝。

03Open Home · 開啟首頁

Open the Home app, or set /odoo/home as the default landing page for your users.
開啟 Home，或把 /odoo/home 設為使用者預設登入頁。

Requirements · 系統需求

  • Odoo 18.0 or 19.0 (Community or Enterprise) · 社群版或企業版皆可
  • Depends on the web module only · 僅相依 web 模組

Data & Privacy · 資料與隱私

This module adds a single user-interface screen. It sends no data anywhere, makes no external calls, and has no telemetry. Everything runs inside your own Odoo instance.
本模組只新增一個操作介面畫面，不傳送任何資料、無外部呼叫、無遙測，全部在你自己的 Odoo 內運行。
